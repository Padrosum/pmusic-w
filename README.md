# pmusic landing page

Static landing page for [pmusic](https://github.com/Padrosum/pmusic). No build step or server runtime is required.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Make sure the default branch is `main`.
3. In **Settings > Pages**, set the source to **GitHub Actions**.
4. Every push to `main` deploys the site automatically.

The page is served from `index.html` at the repository root. The `.nojekyll` file also keeps it compatible with branch-based Pages deployments.
